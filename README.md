# weaveblob

Weave structured JSON blob payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/weaveblob/

## Install / run

```bash
git clone https://github.com/theworker02/weaveblob.git
cd weaveblob
node src/cli.js
node --test
```
